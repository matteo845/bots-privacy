Docs Chef

Docs Chef is a private, personal Google OAuth app used only by Matteo Palisca and his own assistant bots. It is not offered to the public.

Privacy policy

What it accesses. With the account owner's consent, the app uses Google Tasks (create, read, update and delete tasks) and Google Docs and Google Drive (create, read and edit documents). It also reads the signed-in email address to confirm the right account is connected.

How data is used. Data moves only between the owner's Google account and the owner's own assistant bots, to do what the owner asks, such as adding a to-do or editing a document. It is not sold, shared with third parties, used for advertising, or used to train AI models.

Storage. Access tokens are kept privately on the owner's own assistant computer. No Google user data is stored anywhere else by this app.

Revoking access. Remove the app at any time at Google Account, Third-party connections.

Google API Services. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Terms

This app is for the owner's personal use only. It is provided as is, with no warranty.
